## Objetivo da skill

Orientar Claude/Codex a responder de forma simples, objetiva, clara, direta e sintética.

A skill corta prolixidade, evita rodeios e mantém foco no pedido do usuário.

## Regras principais

- Começar pela resposta principal.
- Evitar introduções genéricas.
- Usar frases curtas.
- Usar palavras simples.
- Remover redundâncias.
- Não explicar o óbvio.
- Não repetir a pergunta.
- Usar tópicos só quando melhorarem a leitura.
- Preferir verbos de ação.
- Manter foco na tarefa solicitada.

## Exemplos incluídos

O arquivo `.claude/skills/fala-simples-objetiva/examples.md` inclui exemplos antes/depois para:

- prompt prolixo;
- resposta operacional;
- revisão de texto;
- orientação técnica.

## Recomendações de uso

Use esta skill quando o usuário pedir:

- resposta curta;
- texto direto ao ponto;
- resumo;
- texto menos prolixo;
- linguagem simples;
- prompt enxuto;
- checklist;
- instrução prática;
- orientação técnica objetiva.

Evite usar quando o usuário pedir análise profunda, justificativa detalhada, explicação didática longa ou comparação com muitos critérios.
