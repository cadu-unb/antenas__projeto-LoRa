# .claude

Contexto local do projeto para trabalho assistido por agentes.

## Skills Referenciadas

- `napkin`: mantem `.claude/napkin.md` como runbook curado do repositorio. Deve ser lido e atualizado no inicio das sessoes e quando houver aprendizado reutilizavel.
- `caveman`: skill/estilo citado pelo usuario. As instrucoes locais dessa skill nao foram encontradas neste ambiente; enquanto isso, tratar como preferencia declarada do projeto e preservar a referencia ate que a skill seja instalada ou documentada.

## Arquivos

- `napkin.md`: runbook vivo, nao um diario de sessao.
- `settings.local.json`: permissoes locais ja existentes para ferramentas Claude/Codex.

## Uso

Ao iniciar trabalho neste repositorio, aplicar primeiro as orientacoes de `napkin.md`, respeitar as skills citadas acima e manter esta pasta focada em memoria operacional reutilizavel.
