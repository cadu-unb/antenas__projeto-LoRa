## 3. Correções arquiteturais obrigatórias

### 3.1 Campo `feasible` em `LinkBatchResult`

**Onde entra:** `propagation/batch/contracts.py` → `LinkBatchResult`.

**Regra:**

```python
feasible: bool = link_margin_db > 0.0
```

**Relação com outros campos:**

| Campo | Relação com `feasible` |
|---|---|
| `link_margin_db` | `feasible = True` se `link_margin_db > 0`; False caso contrário |
| `link_risk` | `feasible = False` ↔ `link_risk = HIGH`; `feasible = True` ↔ `link_risk` ∈ {LOW, MEDIUM} |
| `sir_decodable` | Independente — enlace pode ser fisicamente viável (`feasible=True`) mas indecodificável por interferência (`sir_decodable=False`) |

**Uso na UI futura:** filtro binário `feasible=True` → exibir como linha verde/amarela; `feasible=False` → exibir como linha vermelha com ícone de bloqueio. Permite ao usuário ocultar enlaces inviáveis de uma única flag sem recalcular margens.

**Onde é calculado:** no executor puro `propagation/batch/executor.py`, imediatamente após calcular `link_margin_db`:

```python
margin_db = link_margin_db(received_power_dbm, request.rx_sensitivity_dbm)
feasible = margin_db > 0.0
```

### 3.2 Nova camada `propagation/batch/`

**Problema:** `LinkPair`, `LinkBatchRequest`, `LinkBatchResult` residem em `gis/multi_link.py`. Se uma página standalone (`pages/link_budget.py`) precisar de `LinkBatchRequest` sem KML, terá que importar de `gis/`, quebrando o isolamento de Bloco 1.

**Solução:** mover contratos para `propagation/batch/contracts.py` e criar executor puro `propagation/batch/executor.py`.

**Papel pós-refatoração de `gis/multi_link.py`:**

```
gis/multi_link.py (ORQUESTRADOR GIS)
  1. Recebe KMLDocument + parâmetros
  2. Computa distâncias geodésicas (geodesic.py)
  3. Roda ray tracing 2D → obstacle_loss_db (ray_tracing_2d.py)
  4. Monta ScalarLinkInput por par (distâncias + perdas pré-calculadas)
  5. Chama execute_link_batch() de propagation/batch/executor.py
  6. Retorna list[LinkBatchResult]

propagation/batch/executor.py (PURO RF)
  1. Recebe LinkBatchRequest + list[ScalarLinkInput]
  2. Aplica Friis escalar para cada par
  3. Calcula margin, feasible, classify_link_risk
  4. Calcula SIR multi-nó (_with_sir)
  5. Retorna list[LinkBatchResult]
```

`execute_link_batch()` **não pode importar:** `gis`, `kml_parser`, `distance_matrix`, `ray_tracing_2d`, `elevation`, `shapely`, `requests`, `streamlit`, `folium`.

### 3.3 Constantes físicas e sensibilidade RX

**Adicionar em `core/constants.py`:**

```python
Z0_OHM = 50.0
EPSILON_0_F_PER_M = 8.854_187_817e-12
MU_0_H_PER_M = 1.256_637_061_435_917e-6
```

**Decisão sobre `DEFAULT_RX_SENSITIVITY_DBM`:**

Adotar **`DEFAULT_RX_SENSITIVITY_DBM = -137.0`**.

Justificativa técnica: SX1276 SF12 BW125 kHz tem sensibilidade real de −136 dBm (Semtech datasheet rev. 7). O valor `−110.0 dBm` é conservador em 27 dB, subestimando cobertura real e marcando como HIGH/MEDIUM enlaces que na prática são LOW. Para ferramenta educacional que deve refletir comportamento real do chipset, `−137.0 dBm` é mais correto.

O valor pode ser sobrescrito por parâmetro em `LinkBatchRequest(rx_sensitivity_dbm=...)` para cenários conservadores ou simulações com margem de engenharia.

**Método de cálculo do MATLAB (flat-earth):**
```
avg_lat = (lat_i + lat_j) / 2
metros_por_grau_lon = 111320 × cos(avg_lat)
dx = (lon_j − lon_i) × metros_por_grau_lon
dy = (lat_j − lat_i) × 111320
distance = √(dx² + dy²)
```

```python
"""Data contracts for batch RF link-budget calculations."""

from __future__ import annotations

from typing import Optional

from pydantic import BaseModel, ConfigDict, Field, field_validator, model_validator

from lora_antenna.antenna.base import Antenna
from lora_antenna.core.constants import (
    DEFAULT_RX_SENSITIVITY_DBM,
    DEFAULT_TX_POWER_DBM,
    LORA_DEFAULT_HZ,
)
from lora_antenna.core.validators import validate_lora_br_frequency_hz
from lora_antenna.propagation.friis import LinkRisk


class LinkPair(BaseModel):
    """Directed node pair with pre-computed 2D geodesic distance."""

    model_config = ConfigDict(frozen=True)

    origin_label: str
    dest_label: str
    distance_m: float

    @model_validator(mode="after")
    def _validate_pair(self) -> "LinkPair":
        if self.origin_label == self.dest_label:
            raise ValueError("origin_label and dest_label must be different.")
        if self.distance_m <= 0:
            raise ValueError("distance_m must be positive.")
        return self


class ScalarLinkInput(BaseModel):
    """GIS-computed scalars for one directed pair passed to the pure executor."""

    model_config = ConfigDict(frozen=True)

    pair: LinkPair
    distance_3d_m: float
    total_extra_loss_db: float = 0.0
    n_buildings_crossed: int = 0

    @model_validator(mode="after")
    def _validate_input(self) -> "ScalarLinkInput":
        if self.distance_3d_m <= 0:
            raise ValueError("distance_3d_m must be positive.")
        if self.total_extra_loss_db < 0:
            raise ValueError("total_extra_loss_db must be non-negative.")
        return self


class LinkBatchRequest(BaseModel):
    """Parameters common to all links in a batch run."""

    model_config = ConfigDict(frozen=True, arbitrary_types_allowed=True)

    pairs: list[LinkPair]
    antenna: Antenna
    tx_power_dbm: float = DEFAULT_TX_POWER_DBM
    frequency_hz: float = LORA_DEFAULT_HZ
    rx_sensitivity_dbm: float = DEFAULT_RX_SENSITIVITY_DBM
    extra_losses_db: float = 0.0
    sf: int = 12

    @field_validator("frequency_hz")
    @classmethod
    def _validate_frequency(cls, value: float) -> float:
        return validate_lora_br_frequency_hz(value)

    @field_validator("extra_losses_db")
    @classmethod
    def _validate_extra_losses(cls, value: float) -> float:
        if value < 0:
            raise ValueError("extra_losses_db must be non-negative.")
        return value

    @field_validator("sf")
    @classmethod
    def _validate_sf(cls, value: int) -> int:
        if value < 7 or value > 12:
            raise ValueError("sf must be between 7 and 12.")
        return value

    @model_validator(mode="after")
    def _validate_request(self) -> "LinkBatchRequest":
        if not self.pairs:
            raise ValueError("LinkBatchRequest requires at least one pair.")
        return self


class LinkBatchResult(BaseModel):
    """Result for one directed link in a multi-node topology."""

    model_config = ConfigDict(frozen=True)

    origin_label: str
    dest_label: str
    distance_m: float
    distance_3d_m: float
    fspl_db: float
    extra_loss_db: float
    received_power_dbm: float
    link_margin_db: float
    link_risk: LinkRisk
    feasible: bool
    sir_db: Optional[float] = None
    sir_decodable: Optional[bool] = None
    interferer_labels: list[str] = Field(default_factory=list)
    n_buildings_crossed: int = 0
```

**Compatibilidade:** campo `feasible` é adição pura — não quebra código que lê campos existentes.

### 5.3 `src/lora_antenna/propagation/batch/executor.py`

**Finalidade:** executor puro de Friis + SIR. Zero imports de GIS.  
**Dependências permitidas:** `propagation/friis.py`, `propagation/interference.py`, `propagation/batch/contracts.py`, `core/`.

```python
"""Pure scalar RF executor for batch link-budget calculations."""

from __future__ import annotations

from collections import defaultdict
from collections.abc import Sequence

from lora_antenna.propagation.batch.contracts import (
    LinkBatchRequest,
    LinkBatchResult,
    ScalarLinkInput,
)
from lora_antenna.propagation.friis import (
    classify_link_risk,
    friis_received_power_dbm,
    fspl_db,
    link_margin_db,
)
from lora_antenna.propagation.interference import sir_db, sir_is_decodable


def execute_link_batch(
    request: LinkBatchRequest,
    scalar_inputs: Sequence[ScalarLinkInput],
) -> list[LinkBatchResult]:
    """Run Friis + SIR for every pre-computed pair.

    All geographic work (distances, obstacle detection, altitude) must be done
    by the caller before invoking this function.
    """
    raw: list[LinkBatchResult] = []

    for scalar in scalar_inputs:
        pair = scalar.pair
        total_loss = scalar.total_extra_loss_db + request.antenna.losses_db
        path_loss_db = fspl_db(scalar.distance_3d_m, request.frequency_hz)

        received_power = friis_received_power_dbm(
            tx_power_dbm=request.tx_power_dbm,
            tx_gain_dbi=request.antenna.gain_dbi,
            rx_gain_dbi=request.antenna.gain_dbi,
            fspl_db=path_loss_db,
            losses_db=total_loss,
        )
        margin = link_margin_db(received_power, request.rx_sensitivity_dbm)

        raw.append(
            LinkBatchResult(
                origin_label=pair.origin_label,
                dest_label=pair.dest_label,
                distance_m=round(pair.distance_m, 1),
                distance_3d_m=round(scalar.distance_3d_m, 1),
                fspl_db=round(path_loss_db, 2),
                extra_loss_db=round(scalar.total_extra_loss_db, 2),
                received_power_dbm=round(received_power, 2),
                link_margin_db=round(margin, 2),
                link_risk=classify_link_risk(received_power, request.rx_sensitivity_dbm),
                feasible=margin > 0.0,
                n_buildings_crossed=scalar.n_buildings_crossed,
            )
        )

    return _with_sir(raw, sf=request.sf)


def _with_sir(
    results: Sequence[LinkBatchResult],
    sf: int,
) -> list[LinkBatchResult]:
    """Annotate every result with SIR given all co-destination links as interferers."""
    by_destination: dict[str, list[LinkBatchResult]] = defaultdict(list)
    for result in results:
        by_destination[result.dest_label].append(result)

    updated: list[LinkBatchResult] = []
    for result in results:
        interferers = [
            other
            for other in by_destination[result.dest_label]
            if other.origin_label != result.origin_label
        ]
        interferer_powers = [item.received_power_dbm for item in interferers]
        interferer_labels = [item.origin_label for item in interferers]

        if interferer_powers:
            sir_value = sir_db(result.received_power_dbm, interferer_powers)
            updated.append(
                result.model_copy(
                    update={
                        "sir_db": round(sir_value, 2),
                        "sir_decodable": sir_is_decodable(sir_value, sf=sf),
                        "interferer_labels": interferer_labels,
                    }
                )
            )
        else:
            updated.append(
                result.model_copy(
                    update={
                        "sir_db": float("inf"),
                        "sir_decodable": True,
                        "interferer_labels": [],
                    }
                )
            )

    return sorted(
        updated,
        key=lambda r: (
            r.sir_decodable is True,
            r.link_margin_db,
            r.sir_db if r.sir_db is not None else float("-inf"),
        ),
        reverse=True,
    )
```

```python
    *,
    distance_matrix: DistanceMatrix | None = None,
    tx_power_dbm: float = DEFAULT_TX_POWER_DBM,
    frequency_hz: float = LORA_DEFAULT_HZ,
    rx_sensitivity_dbm: float = DEFAULT_RX_SENSITIVITY_DBM,
    buildings: Sequence[KMLPolygon] | None = None,
    extra_losses_db: float = 0.0,
    nominal_db_per_building: float = 15.0,
    sf: int = 12,
    directed: bool = True,
) -> list[LinkBatchResult]:
    """Orchestrate KML geometry, distances, ray tracing, then delegate RF to executor.

    Block 1 functions receive only scalar values; all KML, polygon, altitude,
    and ray-tracing concerns remain inside this GIS layer.
    """
    if len(doc.points) < 2:
        raise ValueError("At least two KML points are required for batch links.")

    validate_lora_br_frequency_hz(frequency_hz)
    matrix = distance_matrix or compute_distance_matrix(doc.positions())
    obstacle_polygons = _default_obstacles(doc, buildings)
    pairs = _build_pairs(doc.points, matrix, directed=directed)

    request = LinkBatchRequest(
        pairs=pairs,
        antenna=antenna,
        tx_power_dbm=tx_power_dbm,
        frequency_hz=frequency_hz,
        rx_sensitivity_dbm=rx_sensitivity_dbm,
        extra_losses_db=extra_losses_db,
        sf=sf,
    )

    scalar_inputs: list[ScalarLinkInput] = []
    for pair in request.pairs:
        origin = _require_point(doc, pair.origin_label)
        destination = _require_point(doc, pair.dest_label)

        n_buildings = count_buildings_crossed(
            origin.latitude,
            origin.longitude,
            destination.latitude,
            destination.longitude,
            obstacle_polygons,
        )
        obstacle_loss_db = building_attenuation_db(n_buildings, nominal_db_per_building)
        total_extra = request.extra_losses_db + obstacle_loss_db
        d3_m = distance_3d_m(origin, destination, pair.distance_m)

        scalar_inputs.append(
            ScalarLinkInput(
                pair=pair,
                distance_3d_m=d3_m,
                total_extra_loss_db=total_extra,
                n_buildings_crossed=n_buildings,
            )
        )

    return execute_link_batch(request, scalar_inputs)


def results_to_sir_matrix(
    results: Sequence[LinkBatchResult],
) -> dict[tuple[str, str], float]:
    """Return {(origin, destination): sir_db} for results with SIR."""
    return {
        (r.origin_label, r.dest_label): r.sir_db
        for r in results
        if r.sir_db is not None
    }


def _build_pairs(
    points: Sequence[KMLPoint],
    matrix: DistanceMatrix,
    *,
    directed: bool,
) -> list[LinkPair]:
    pairs: list[LinkPair] = []
    for i, origin in enumerate(points):
        for j, destination in enumerate(points):
            if i == j:
                continue
            if not directed and j <= i:
                continue
            pairs.append(
                LinkPair(
                    origin_label=origin.label,
                    dest_label=destination.label,
                    distance_m=matrix.get_distance(origin.label, destination.label),
                )
            )
    return pairs


def _default_obstacles(
    doc: KMLDocument,
    buildings: Sequence[KMLPolygon] | None,
) -> list[KMLPolygon]:
    if buildings is not None:
        return list(buildings)
    return doc.polygons_by_role(KMLPolygonRole.BUILDING, KMLPolygonRole.OBSTACLE)


def _require_point(doc: KMLDocument, label: str) -> KMLPoint:
    point = doc.get_point(label)
    if point is None:
        raise KeyError(f"KML point not found: {label}")
    return point
```

**Observação de compatibilidade:** `results_to_sir_matrix()` e `run_link_budget_batch()` mantêm assinatura idêntica. Código que importava `LinkPair`, `LinkBatchRequest`, `LinkBatchResult` de `gis/multi_link` precisa atualizar o import para `propagation/batch/contracts`.

### 5.6 `src/lora_antenna/gis/distance_matrix.py`

**Finalidade:** calcular e armazenar matriz de distâncias geodésicas com rastreabilidade de método.  
**Mudanças:** adicionar `DistanceMatrixEntry` e novo `DistanceMatrix` Pydantic; manter `compute_distance_matrix` e `distance_for_pair` compatíveis.

```python
"""Distance matrix calculation for KML/GIS nodes."""

from __future__ import annotations

from collections.abc import Iterable

from pydantic import BaseModel, ConfigDict, Field

from lora_antenna.gis.geodesic import geodesic_distance_m
from lora_antenna.models.geo import GeographicPosition


class DistanceMatrixEntry(BaseModel):
    """One directed (or undirected) distance measurement with method metadata."""

    model_config = ConfigDict(frozen=True)

    origin_label: str
    dest_label: str
    distance_m: float = Field(..., gt=0)
    method: str = "WGS84_GEODESIC"
    delta_reference_m: float | None = None


class DistanceMatrix(BaseModel):
    """Collection of geodesic distances with lookup helpers."""

    model_config = ConfigDict(frozen=True)

    entries: list[DistanceMatrixEntry]

    def to_dict(self) -> dict[tuple[str, str], float]:
        """Return upper-triangular dict compatible with legacy callers."""
        return {(e.origin_label, e.dest_label): e.distance_m for e in self.entries}

    def get_distance(self, origin_label: str, dest_label: str) -> float:
        """Return distance for a pair regardless of tuple orientation."""
        for entry in self.entries:
            if (
                entry.origin_label == origin_label
                and entry.dest_label == dest_label
            ) or (
                entry.origin_label == dest_label
                and entry.dest_label == origin_label
            ):
                return entry.distance_m
        raise KeyError(
            f"Distance not found for pair {origin_label}->{dest_label}."
        )

    def annotate_delta(
        self,
        reference: dict[tuple[str, str], float],
    ) -> "DistanceMatrix":
        """Return a copy with delta_reference_m filled from a reference dict."""
        updated = []
        for entry in self.entries:
            ref_dist = reference.get(
                (entry.origin_label, entry.dest_label),
                reference.get((entry.dest_label, entry.origin_label)),
            )
            delta = (
                round(entry.distance_m - ref_dist, 2)
                if ref_dist is not None
                else None
            )
            updated.append(entry.model_copy(update={"delta_reference_m": delta}))
        return DistanceMatrix(entries=updated)


def compute_distance_matrix(
    positions: Iterable[GeographicPosition],
    *,
    precision_m: int = 1,
) -> DistanceMatrix:
    """Compute upper-triangular 2D Haversine distance matrix."""
    points = list(positions)
    entries: list[DistanceMatrixEntry] = []

    for i, origin in enumerate(points):
        for destination in points[i + 1 :]:
            entries.append(
                DistanceMatrixEntry(
                    origin_label=origin.label,
                    dest_label=destination.label,
                    distance_m=round(geodesic_distance_m(origin, destination), precision_m),
                )
            )

    return DistanceMatrix(entries=entries)


def distance_for_pair(
    matrix: DistanceMatrix,
    origin_label: str,
    dest_label: str,
) -> float:
    """Convenience wrapper; delegates to DistanceMatrix.get_distance()."""
    return matrix.get_distance(origin_label, dest_label)
```

**Observação de compatibilidade:** código antigo que usava `DistanceMatrix = dict[tuple[str,str], float]` precisa chamar `.to_dict()` ou `.get_distance()`. O tipo `DistanceMatrix` agora é a classe Pydantic.

```python
def normalize_pair(origin_label: str, dest_label: str) -> tuple[str, str]:
    """Return canonical (alphabetically-first, second) pair."""

        return (origin_label, dest_label)

    origin_label: str,
    dest_label: str,
    computed_distance_m: float,
) -> float | None:

    ref = reference_distance_m(origin_label, dest_label)
    if ref is None:

    return round(computed_distance_m - ref, 2)
```

## 7. Manual do usuário: Simulador Multi-Nó LoRa

### 7.1 Finalidade

O simulador calcula a viabilidade de comunicação entre pontos de acesso LoRa no Campus Darcy Ribeiro da Universidade de Brasília. Para cada par de nós (P1–P8), ele:

1. **Lê o KML** com posições geográficas e prédios do campus
2. **Identifica nós LoRa** (P1–P8) e prédios/obstáculos
3. **Calcula distâncias** geodésicas entre todos os pares
4. **Estima perdas**: espaço livre (FSPL) + atenuação por prédios atravessados
5. **Calcula potência recebida** via equação de Friis
6. **Calcula margem de enlace**: potência recebida − sensibilidade do receptor
7. **Calcula SIR**: relação sinal-interferência considerando todos os nós transmitindo para o mesmo destino
8. **Classifica risco** (Baixo / Médio / Alto) e viabilidade (Viável / Inviável)
9. **Propõe canais** para reduzir interferência co-canal entre nós próximos

> **Limitação importante:** o simulador usa modelo de propagação em espaço livre (Friis). Não modela multipercurso, fading, difração exata, nem efeitos de temperatura. Use os resultados como **estimativa educacional**, não para decisões críticas de produção sem validação de campo.

### 7.4 Interpretação das métricas

| Métrica | Unidade | O que significa |
|---|---|---|
| **dBm** | decibel-milliwatt | Potência em escala logarítmica. 0 dBm = 1 mW. Cada +3 dB ≈ dobra a potência. |
| **Potência recebida (Pr)** | dBm | Estimativa da potência que chega ao receptor. Quanto maior (menos negativo), melhor. |
| **Margem de enlace** | dB | Pr − sensibilidade RX. Positiva = enlace viável. > 20 dB = robusto. < 0 dB = inviável. |
| **SIR** | dB | Relação entre sinal desejado e soma dos interferentes co-canal. Quanto maior, melhor. |
| **Limiar LoRa** | dB | SIR mínimo para decodificar: SF7=10 dB, SF8=9 dB, ..., SF12=6 dB. |
| **Risco BAIXO** | — | Margem > 20 dB. Enlace robusto, confiável em condições normais. |
| **Risco MÉDIO** | — | 0 < margem ≤ 20 dB. Enlace viável mas sensível a variações de ambiente. |
| **Risco ALTO** | — | Margem ≤ 0 dB. Enlace inviável pela potência recebida. |
| **Viável** | — | `feasible = True` ↔ margem > 0. Filtro rápido para UI. |
| **Inviável** | — | `feasible = False` ↔ margem ≤ 0 dB. Enlace fisicamente bloqueado. |
| **Interferência co-canal** | — | Dois nós transmitindo na mesma frequência chegam ao mesmo destino com SIR insuficiente. |

**Exemplo prático (P2→P5 com P4→P5 como interferer):**

```
d(P2,P5) ≈ 337 m → Pr ≈ −65 dBm
d(P4,P5) ≈ 271 m → Pr ≈ −63 dBm (mais forte → mais interferente)
SIR = −65 − (−63) = −2 dB < 6 dB (limiar SF12)
→ sir_decodable = False
→ Solução: atribuir canal diferente a P2 ou P4
```

### 7.5 Erros comuns e correções

| Problema | Causa provável | Solução recomendada |
|---|---|---|
| "KML sem pontos" | Arquivo KML não contém `<Placemark>` com pontos | Verifique se exportou como `.kml` (não `.kmz`). Abra o arquivo em editor de texto e verifique `<Point>` tags. |
| Todos os enlaces em risco ALTO | Sensibilidade RX muito alta (menos negativa que o esperado) | Verifique campo "Sensibilidade RX" — use −137 dBm para SX1276 SF12. |
| Distâncias incorretas | Coordenadas GPS erradas no KML | Verifique no Google Earth se os marcadores estão nas posições corretas. |
| SIR = ∞ para todos os pares | Apenas 1 nó no KML, ou par único sem outros interferentes | Normal quando há apenas 2 nós ou nenhum nó transmite no mesmo canal. |
| Prédio não detectado como obstáculo | Nome do polígono não contém "BUILDING" ou "OBSTACLE" | Renomeie o polígono no Google Earth seguindo a convenção de nomenclatura. |
| "At least two KML points required" | KML contém apenas 1 ponto | Adicione pelo menos 2 marcadores antes de executar a simulação. |
| Polígono degenerado corrigido | KML exportado com geometria auto-intersectante | Sem ação necessária — o sistema corrige automaticamente com `buffer(0)`. Verifique no mapa se o contorno do prédio está visualmente correto. |
| Altitude SRTM timeout | Serviço `opentopodata.org` indisponível ou sem internet | Desmarque "Usar altitude SRTM" — o sistema usa altitude 0 m (plano) como fallback. |

## 10. Nota metodológica de governança

A pasta `_doc/_plan/` registra planejamento, intenção arquitetural, hipóteses e especificações anteriores à implementação. A pasta `_doc/_report/` registra verificações sobre código real, auditorias, correções operacionais e decisões tomadas após inspeção da implementação existente.

Este documento pertence a `_doc/_report/` porque:

1. Parte da auditoria Rise 5 (`rise_5_auditoria_codigo_real.md`) como fonte primária de desvios
2. Compara planejamento V1 Spec com implementação real encontrada em `src/`
3. Converte ressalvas técnicas em ações de correção com código executável
4. Documenta decisões tomadas com base em evidências de código real (não hipóteses)
5. Inclui a tabela de referência P1–P8 derivada de arquivo legado real (`EnlacesLora.m`), não de especificação abstrata

A separação entre `_plan` e `_report` garante rastreabilidade, controle de qualidade e sincronismo entre arquitetura pretendida e código efetivamente implementado. Documentos em `_report/` são fonte autoritativa para o estado atual do sistema; documentos em `_plan/` são fonte autoritativa para a intenção original, que pode ou não ter sido implementada conforme especificado.

> **Gate de saída CP-4:** este documento, ao ser executado, resolve os 4 desvios identificados na auditoria Rise 5 e habilita o projeto a avançar para CP-4 (UI Standalone) com arquitetura íntegra.
