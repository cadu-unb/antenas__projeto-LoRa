# backend/data/

Dados persistidos em disco. Gerado pelo sistema em runtime. Não versionar conteúdo.

## Subpastas

| Pasta | Conteúdo |
|---|---|
| `antenna_specs/` | Specs de antenas salvas (`{id}.json`) |
| `simulations/` | Logs e resultados de simulações (`{job_id}/`) |
| `kml_uploads/` | Arquivos KML importados pelo usuário |
| `reports/` | Relatórios exportados gerados pelo sistema |
